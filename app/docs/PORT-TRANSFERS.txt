NEXUS MANAGER: COMPLETE PORT FOLDER TRANSFERS
Nexus Manager 0.1.10 / PORTS1 test build, 26 October 2026

Select a port in My games, choose Copy game or Move game, and confirm.
Nexus reads the forwarder's target and automatically selects the complete
port folder. There is no file-selection or extra-folder setup screen.

Example:
  sdmc:/switch/left4dead -> usb:/switch/left4dead
Every file and subfolder is included: game data, runtime, configuration,
hidden files, local saves and files added since the original installation.
USB-to-SD uses the same process in reverse. Known separate data folders
from the inspected Ports catalogue are included automatically, in full.

Files are read back and verified before creating the destination HOME
shortcut. The shortcut preserves launch arguments and address-space type;
USB shortcuts use the project's existing Nexus Virtual SD loader.
Copy keeps both copies. Move removes source files only after destination
verification and shortcut creation. Existing different destination files
stop the transfer; identical files can be reused. Cancellation or errors
leave the verified destination available if source removal has begun.

The old HOME shortcut is retained. Remove it in System Settings after
testing the new shortcut. Empty source directories may remain after a move.
Shared Wine runtime folders are copied completely and retained at source
so other ports continue to have their files. Atmosphere/firmware files stay
on physical SD. Console-managed save data is not part of folder transfers.

Catalogue: all 72 NSP packages in B2 Ports were inspected through read-only
listing and metadata reads. The 45 NSZ packages were listed, not inspected.
Mass Effect and NOVA 3 have mismatched packaged launch targets; automatic
transfer is refused for those original shortcuts until corrected.
PORT-FOLDER-CATALOG.txt records all application names and folder locations.
