# Source attribution

USB Loader is a modified independent fork of **Sphaira 1.0.7** by NaGaa95 and its
contributors, commit 99b6f08fd5c3effeb99df0130850403bd150fb33.
Upstream: https://github.com/NaGaa95/sphaira

The GPL-3.0 license, original source copyright notices, third-party license files
and upstream reference README are preserved. Upstream identifiers/source directory
names remain internal implementation details, not app branding or updater targets.

TechRepairs4U's Nexus adaptation adds the original app identity/dashboard,
physically scoped storage operations, shared USB service integration, verified
copy/removal flow, reviewed placeholder cleanup and repository-scoped updater.
The menu pictograms are original code-defined vectors. The NRO icon was
AI-generated; its prompt is preserved under assets/branding.

The source release vendors exact fetched dependency revisions in vendor/ and lists
origins in DEPENDENCIES.json. Each dependency retains its own notices. Build SDK
and toolchain libraries are external dependencies, not part of this repository.

The HTTPS CA file contains Mozilla public trust roots extracted by curl; see
assets/romfs/certs/README.md. It contains no private key.
